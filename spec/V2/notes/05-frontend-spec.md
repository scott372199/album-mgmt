## 1. 全局框架 / Global shell

### 1.1 布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏 56px   logo · 站点切换 · 账期/口径选择 · 数据时间 · 用户 │
├──────────┬───────────────────────────────────────────────────┤
│ 侧栏     │  内容区（最大宽 1360px，居中，左右留白 ≥ 24px）    │
│ 200px    │                                                   │
│ 三组导航 │  ┌ 页面标题 + 一句话结论 ───────────────────────┐ │
│          │  │ 主内容块（卡片，圆角 12px，间距 16px）        │ │
│          │  └───────────────────────────────────────────────┘ │
└──────────┴───────────────────────────────────────────────────┘
```

| 区域 | 规格 |
| --- | --- |
| 顶栏 | 固定，高 56px，白底，1px 下边框；右侧三个选择器（站点 / 账期 / 口径）+ 数据时间徽标 |
| 数据时间徽标 | 显示 `asOf` 相对时间（「12 分钟前」），点击弹出各数据源新鲜度；超过 SLA 变琥珀色 |
| 侧栏 | 固定，宽 200px，三组导航，当前项左侧 3px 竖条 + 淡底 |
| 内容区 | 12 列栅格，`gap: 16px`，最大宽 1360px |
| 卡片 | `background: var(--card)`，圆角 12px，`border: 1px solid var(--line)`，内边距 20px，无阴影 |

### 1.2 导航分组

导航项后的数字徽标只显示 `CRITICAL` 级未处理数量，其余用灰点，避免"红色疲劳"。

### 1.3 四条全局交互约定

| # | 约定 |
| --- | --- |
| U1 | **每个数字都能点开**。指标卡、分组行、成本数字、告警计数，点击都要落到明细列表或原始证据。 |
| U2 | **每个列表都自带空态与降级态**，且文案不同（见 §3）。 |
| U3 | **筛选条件写进 URL**，刷新与分享后结果一致。 |
| U4 | **破坏性/不可逆操作必须二次确认**（触发 apply、豁免结论、改配置），确认弹层展示将被影响的对象数量。 |

规则：

| # | 规则 |
| --- | --- |

## 2. 页面规格 / Page specifications

每页固定三段：**一句话结论** → **主视图** → **明细/证据**。三段缺一不可——只有图表没有结论等于把分析工作丢回给用户。

### 2.1 总览 `#/`

| 区块 | 高度 | 内容 | 数据来源 |
| --- | --- | --- | --- |
| 结论条 | 56px | 一句话：本期成本、环比、最大异常、待办数 | `GET /cost/summary`、`GET /drift/findings?severity=CRITICAL`、`GET /inventory/gates` |
| KPI × 4 | 96px | 月成本 / 漂移（CRITICAL 数）/ 发布成功率 / 未完成待办 | 同上 + `GET /delivery/metrics` |
| 成本趋势 | 320px，全宽 | 12 个月折线 + 面积，可切三口径；底部叠加状态条（三云 + 环境健康） | `GET /cost/trend` |
| 异常与待办 | 240px，全宽一张卡 | 左：4 个治理指标（漂移/安全/覆盖率/发布）；右：4 条待办，每条标「触发自 XX 指标」 | 多端点聚合 |
| 成本构成 + 节省 | 280px，2 列 | 左：按 site 的堆叠条；右：节省建议 top 4 | `GET /cost/summary?groupBy=site`、`GET /cost/savings` |

交互：

- 点击 KPI 卡 → 跳对应页并带上筛选（如点"漂移 CRITICAL"→ `#/drift?severity=CRITICAL`）。
- 趋势图切换口径时，X 轴刻度不动，Y 轴重绘 + 200ms 过渡，左上角出现「口径已切换」提示 3 秒。
- 待办每条必须有「触发自」链接，点进去能看到产生它的指标。

图表规格（`spark` / `trend`）：线宽 2px，面积填充 `rgba(138,112,137,.10)`，端点圆点 `r=3.5`，网格仅水平线 `--line-soft`，Y 轴 4 档刻度，不在图上标数据点（hover 才出 tooltip）。

## 3. 状态矩阵 / State matrix

每个数据区块必须实现四种状态，文案不能复用。

| 状态 | 触发 | 渲染 |
| --- | --- | --- |
| **加载** | 首次请求 | 骨架块，高度与目标一致，不做全屏 spinner |
| **空** | 请求成功、0 条 | 图标（线性）+ 一句事实 + 一个动作。例：「这个筛选下没有漂移。清除筛选」 |
| **降级** | 响应含 `degraded[]` | 黄条横幅 + 区块内数据不变，横幅文案点名数据源与最后成功时间 |
| **错误** | 5xx / 网络失败 | 区块内错误块 + 「重试」按钮 + `traceId`（可复制） |

**空态与错误态必须视觉不同**：空态用 `--sage`，错误态用 `--clay`。

## 4. 图表实现规范 / Chart implementation

| 图 | 技术 | 关键参数 |
| --- | --- | --- |
| 趋势折线 | 手写 SVG `path` + 面积 `path` | 线宽 2，圆角端点，网格 4 条水平线 |
| 堆叠条 | SVG `rect` 序列 | 段间 2px 间隙，段内不描边 |
| 瀑布图（差异桥） | SVG `rect` + 连接线 | 正负用 `--clay` / `--sage`，零轴 1px |
| 拓扑图 | SVG + 固定坐标 | 见 §2.3 |
| 严重度分布 | 单条横向堆叠 | 四段，附图例与计数 |
| 迷你趋势（KPI 卡内） | SVG 24×64 | 无坐标轴，仅形状 |

统一要求：

| # | 要求 |
| --- | --- |
| CH1 | 所有 SVG 带 `role="img"` 与 `<title>`，供读屏。 |
| CH2 | 颜色通过 `currentColor` 或与 CSS 变量同值的常量，不出现随机 hex。 |
| CH3 | 无数据时画空坐标系 + 中心文案，不画一条 0 线。 |
| CH4 | hover 才出 tooltip，tooltip 内必须含口径/精度/时间。 |
| CH5 | 不使用动画的图表（趋势、堆叠）在切换筛选时保持 Y 轴范围稳定，避免"跳动误导"。 |

| `Money` | 金额 | 必填四元组，缺字段时渲染错误占位（开发期红框） |
| `Chip` | 状态/口径/云 | 三种色系：state（sage/clay/sand/slate）、basis（plum）、cloud |
| `DataTable` | 列表 | 虚拟滚动、列宽可拖、排序白名单、行点击打开抽屉 |
| `Drawer` | 详情 | 右侧 480px，ESC 关闭，URL 携带 `?sel=` |
| `Banner` | 降级/警示 | 三色：info(sand)/warn(sand)/error(clay)，不可关闭（降级类） |
| `EmptyState` / `ErrorState` | 见 §3 | 文案必填，不允许默认文案 |
| `ConfirmDialog` | 二次确认 | 显示影响对象数量与不可逆说明 |
| `Timeline` | 演练记录、事件流 | 左侧竖线 + 圆点，时间右对齐 |
| `DiffViewer` | 漂移/变更 | 左右两栏 JSON，差异行高亮，折叠超过 20 行 |
